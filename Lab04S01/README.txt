Lab04S01 - Caracterização do Dataset
=====================================

Conteúdo do pacote:
- dataset_characterization.csv : dataset sintético de exemplo (200 repositórios).
- summary_by_language.csv : resumo por linguagem (contagem e métricas).
- chart_language_distribution.png : gráfico de barras com distribuição por linguagem.
- chart_stars_by_language.png : boxplot de stars por linguagem.
- chart_repos_by_year.png : séries temporais de repositórios criados por ano.
- report_lab04s01.md : relatório com explicações e instruções para substituição pelo dataset real.

Objetivo:
Gerar a entrega (Lab04S01) com a caracterização do dataset e arquivos que podem ser usados no Power BI / Tableau / Google Data Studio.
